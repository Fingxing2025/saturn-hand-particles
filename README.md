# 土星粒子场

一个面向作品展示的实时交互粒子场实验：使用 Three.js 构建纯粒子化的土星结构，用 MediaPipe 读取单手手势，把手掌张合映射到轨道扩张、亮度变化、混沌扰动与整体现象级爆炸。

它不是传统的参数面板演示，而是更接近一个可被手势直接驱动的视觉装置。

## 项目亮点

- 纯粒子土星：中心球体、主环、外环和尘埃层都由粒子构成，没有依赖实体球壳来撑造型。
- 手势驱动：手掌持续张开会推动土星放大、增亮并失稳，某一刻突然张开手掌会触发整体爆炸。
- 双模式体验：提供摄像头实机页和独立 Demo 页，既能实时交互，也能在没有摄像头的情况下完整展示视觉效果。
- 电影感调色：场景包含 Bloom、色偏、闪爆、冲击波式运动和暗背景下的高亮粒子层次。
- 可演示性强：支持鼠标拖拽旋转、滚轮缩放、阶段巡演、手动触发爆炸和全屏展示。

## 你能看到什么

### 实机交互页

- 摄像头识别单手手势并输出张合度。
- 张合度驱动中心粒子球、环带半径、亮度和混沌程度。
- 快速张开手掌时，整颗星球会从中心爆开，粒子高速飞离视野后再缓慢回收。
- HUD 会显示当前张合百分比、混沌强度和状态提示。

### Demo 展示页

- 自动巡演六个阶段：收束静息、稳定扩张、高亮巡航、临界混沌、爆散峰值、回落重聚。
- 支持滑杆拖动任意张合值，便于观察不同状态下的粒子结构。
- 提供阶段按钮、重新播放、暂停巡演和手动触发爆炸按钮。
- 不依赖摄像头，适合录屏、作品集展示和快速预览。

## 技术构成

- Three.js：场景、相机、粒子几何、着色器和后处理。
- 自定义粒子材质：统一控制粒径、辉光、闪烁、爆炸冲量和受光表现。
- MediaPipe Hand Landmarker：实时提取手部关键点并转换为手掌张合度。
- TypeScript + Vite：开发体验、类型约束和构建流程。

## 本地运行

```bash
npm install
npm run dev
```

启动后可访问：

- `/`：摄像头实机交互页
- `/demo.html`：无摄像头的演示页

## 生产构建

```bash
npm run build
```

## 交互方式

- 鼠标拖拽：旋转土星视角
- 鼠标滚轮：缩放镜头
- 手掌持续张开：推动星球扩张、提亮并进入混沌
- 手掌突然张开：触发整体爆炸
- Demo 页按钮：切换阶段、暂停巡演、手动爆炸

## 项目结构

- `src/main.ts`：摄像头实机页入口与 HUD 状态联动
- `src/demo.ts`：展示模式、阶段巡演、滑杆与按钮交互
- `src/handTracking.ts`：手势识别、张合度计算与爆炸触发判定
- `src/saturnScene.ts`：核心粒子场、相机运动、后处理和爆炸动画
- `src/style.css`：实机页与 Demo 页共享样式

## 实现备注

- MediaPipe 模型和 WASM 资源已放在 `public/` 目录，本地开发时会随 Vite 一起提供。
- 首次打开实机页需要允许摄像头权限；如果只想看效果，可以直接使用 Demo 页。
- Hand Landmarker 会优先尝试 GPU delegate，失败后自动回退到 CPU。
